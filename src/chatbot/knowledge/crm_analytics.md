# Analytics in Pyro

Pyro analytics covers live CRM/ERP metrics for the current tenant.

## What you can ask the assistant
- "Show analytics" — snapshot of leads, tickets, inventory
- "How many unresolved tickets?"
- "Break down tickets by resolution_status"
- "Lead status breakdown"
- "Inventory request status overview"

## Product analytics surfaces
- CSE analytics: overview, members, time-series
- Team / RM dashboards
- Saved analytics boards
- NL→SQL analytics query for support-ticket style questions

## Notes
- Live numbers always come from tenant-scoped tools (never guessed).
- SLA / resolution time live on support_ticket JSON fields.
